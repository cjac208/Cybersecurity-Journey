## Core Engineering Projects

### 1. [Automated Threat Intelligence Log Parser & Scanner](./01_Security_Engineering_%26_Automation/Automated_Log_Parser/)
* **Core Function:** Automated security scanner for enterprise web server traffic.
* **How it Works:** Programmatically ingests high-volume web logs, leverages optimized Regular expressions (Regex) to instantly isolate malicious traffic signatures, and auto-generates simplified daily security summaries to eliminate manual analytical overhead.
* **Tech Stack:** Python, Regular Expressions (Regex), Logging, File I/O Optimization.

### 2. [Cloud Configuration Auditor (CSPM Tool)](./01_Security_Engineering_%26_Automation/Cloud_Security_Configuration_Auditor/)
* **Core Function:** Enterprise-grade Cloud Security Posture Management automation.
* **How it Works:** Programmatically connects to cloud infrastructure, discovers active S3 buckets, parses complex IAM access policies, and evaluates master safety switches to flag exploitable data exposures via real-time alerts.
* **Tech Stack:** Python, AWS Boto3 SDK, IAM Policy Parser, AWS CLI.

### 3. [Automated Vulnerability Scanner & Reporter](./01_Security_Engineering_%26_Automation/Vulnerability_Scanner/)
* **Core Function:** Programmatic vulnerability management and lifecycle auditing.
* **How it Works:** Scans local software asset inventories, programmatically queries the NIST National Vulnerability Database (NVD) API v2, maps exposures to active CVE/CVSS metrics, and outputs stakeholder-ready Markdown remediation roadmaps.
* **Tech Stack:** Python, REST APIs (NIST NVD v2), JSON Parsing, Markdown Engine.
