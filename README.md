## Core Engineering Projects

### 1. [High-Performance Log Automation & Diagnostic Parser](./01_Security_Engineering_%26_Automation/Automated_Log_Parser/)
* **Core Function:** High-volume automated diagnostic scanner for web server log infrastructure.
* **How it Works:** Programmatically streams enterprise web access logs line-by-line, utilizing optimized Regular Expressions (RegEx) to isolate system errors or configuration anomalies, and auto-generates structured daily summaries to eliminate manual troubleshooting metrics.
* **Tech Stack:** Python, Regular Expressions (RegEx), Systems Performance Tuning, Log Architecture.

### 2. [AWS Cloud Resource Configuration Auditor](./01_Security_Engineering_%26_Automation/Cloud_Security_Configuration_Auditor/)
* **Core Function:** Enterprise-grade cloud environment compliance and configuration tracking automation.
* **How it Works:** Programmatically interacts with cloud storage via software development kits, discovers active infrastructure resources, parses nested configuration policies, and evaluates master switches to flag environment drift via real-time alerts.
* **Tech Stack:** Python, AWS Boto3 SDK, Environment Configuration Management, Cloud Auditing, Moto Library.

### 3. [Automated Asset Auditing & Diagnostic Tool](./01_Security_Engineering_%26_Automation/Vulnerability_Scanner/)
* **Core Function:** Programmatic software inventory management and operational compliance lifecycle auditing.
* **How it Works:** Ingests local asset tracking configuration data, programmatically queries live software baseline configurations via external third-party REST APIs, and auto-generates structured Markdown technical assessments detailing infrastructure updates.
* **Tech Stack:** Python, REST APIs, JSON Data Parsing, Markdown Reporting Engine.
